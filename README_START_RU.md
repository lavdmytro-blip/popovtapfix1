# POPOV TAP + PostgreSQL — запуск

Это **демонстрационный MVP**, не готовый масштабируемый игровой сервис. Один экземпляр Node.js использует PostgreSQL для сохранения баланса, профилей, скинов, заданий и рейтинга игроков. Счёт — игровые очки, не криптовалюта.

## Хостинг (Northflank или любой Node.js хостинг)
1. Создай PostgreSQL database и скопируй **DATABASE_URL**.
2. Создай сервис Node.js из этого репозитория.
3. Установи переменные окружения **BOT_TOKEN** и **DATABASE_URL** (не коммить токен).
4. Build: `npm install`, Start: `npm start`; PORT выставляет провайдер.
5. Публичный HTTPS URL сервиса укажи через @BotFather для кнопки Mini App.
6. Открой игру **из Telegram-бота**, не в обычном браузере. В браузере без initData будет демо-профиль.

## Локально
Установи Node.js 20+, PostgreSQL, выполни `npm install`, установи BOT_TOKEN и DATABASE_URL, затем `npm start`.

## Ограничения
- Один серверный процесс / одна реплика. Состояние в памяти синхронизируется с JSONB-строкой PostgreSQL; горизонтальное масштабирование приведёт к конфликтам. Для нагрузки нужна нормализованная схема и транзакции на игрока.
- Игровые баллы сохраняются в БД после каждого изменения. При первом запуске БД пустая: старый `data.json` автоматически **не импортируется**. Сохрани резервную копию прежней базы.
- Аватар Telegram может не приходить в Mini App `initData`, и тогда будет показана буква имени. Username берётся из подтверждённых Telegram данных.
- Покупки Telegram Stars требуют отдельного тестирования, защиты и соответствия правилам Telegram. Не включай реальные оплаты до проверки обработки и возвратов.
- Не публикуй свой BOT_TOKEN или DATABASE_URL и не добавляй их в репозиторий.
