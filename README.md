# 👑 POPOV TAP

Оригинальная игра-кликер для Telegram Mini Apps, вдохновлённая жанром tap-to-earn, а не копия интерфейса Notcoin.

## Мгновенный запуск демоверсии
Откройте `public/index.html` **через локальный HTTP-сервер**, поскольку картинка `coin.png` должна лежать рядом с HTML. Без авторизации Telegram игра работает в деморежиме и сохраняет прогресс в браузере.

Например, в папке `public`:
```sh
python -m http.server 8080
```
Откройте http://localhost:8080

## Сервер Telegram Mini App (Node.js 20+)
```sh
# Linux/macOS
BOT_TOKEN='YOUR_TOKEN_FROM_BOTFATHER' PORT=3000 node server.js
# Windows PowerShell
$env:BOT_TOKEN='YOUR_TOKEN_FROM_BOTFATHER'; node server.js
```
Откройте http://localhost:3000 — вне Telegram это деморежим.

Чтобы подключить бота, создайте своего бота через @BotFather и настройте **HTTPS URL** Mini App на домене, на котором запущен сервер; проксируйте HTTPS к localhost:3000. Никогда не вставляйте токен бота в HTML или публичный репозиторий. При открытии из Telegram клиент отправит `initData`, которое сервер проверяет по подписи Telegram.

## Что реализовано
- Тапы с ограничением частоты, энергия, восстановление, ежедневный пассивный доход, upgrades.
- 3 достижения, игровое накопление и собственный дизайн с фото-монетой.
- 4 скина, из них 3 косметических за Stars, бесплатные улучшения за игровые очки.
- Демо: локальное сохранение; Telegram: сессии и игровые данные на сервере.
- Telegram Stars: создание инвойса `XTR`, проверка `pre_checkout_query`, подтверждение только по `successful_payment`, защита от повторного начисления одного платежа.

## Важные ограничения перед публичным релизом
- Это **MVP/прототип**, не готовый коммерческий сервис. Для реальных пользователей замените файл `data.json` и память сервера транзакционной БД; добавьте резервные копии, защиту сессий, журнал платежей, поддержку возвратов, условия использования, политику конфиденциальности, антибот, тесты и мониторинг.
- `getUpdates` нельзя использовать вместе с Telegram webhook. Работает один процесс сервера.
- В деморежиме покупки за Stars **не** производятся; в Telegram оплата — реальная, только если вы настроили работающий бот и сервер. Протестируйте в Telegram test environment прежде чем включать продажи.
- Очки POPOV не являются токенами на блокчейне, не обмениваются на деньги и не предполагают прибыль. Нет криптокошелька или реальной токеномики.
- Не обещайте доход ни игрокам, ни владельцу проекта. Дополнительные возможности Telegram Stars и правила для пользователей проверяйте по актуальной документации: https://core.telegram.org/bots/payments-stars и https://core.telegram.org/bots/webapps.
