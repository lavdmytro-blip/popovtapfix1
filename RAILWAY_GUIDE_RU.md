# Запуск POPOV TAP на Railway

1. Загрузите содержимое этой папки в корень приватного GitHub-репозитория (package.json, server.js, public/).
2. Railway → New Project → Deploy from GitHub repo → выбрать репозиторий.
3. В Railway → сервис → Variables: BOT_TOKEN = токен из @BotFather. Никому его не отправлять.
4. В Railway → сервис → Settings → Networking → Generate Domain. Проверьте, что HTTPS-ссылка открывает игру.
5. Для сохранения прогресса: сервис → Volumes → Add Volume; Mount Path = /data; добавьте Variables: DATA_FILE=/data/data.json. Переразверните сервис. Используйте только одну реплику приложения.
6. В @BotFather выберите своего бота → Bot Settings → Menu Button → Configure menu button; укажите полученную HTTPS-ссылку. Название кнопки: Play POPOV TAP. Интерфейс BotFather может отличаться.
7. Откройте бота в Telegram и нажмите кнопку меню. Проверяйте авторизацию, сохранение прогресса и косметические покупки только в тестовом окружении перед реальными платежами.

Примечания: само приложение является MVP, для коммерческого запуска требуется аудит платежей, хранение записей, защита от накрутки, политика конфиденциальности, механизмы возврата и поддержки. Сервер использует long polling Telegram; не настраивайте webhook параллельно. Если уже есть webhook, отключите его до запуска polling. Не запускайте более одной копии процесса. Без Volume прогресс после перезапуска может пропасть.
