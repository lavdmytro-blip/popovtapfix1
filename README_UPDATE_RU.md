# POPOV TAP — Royal Edition

## Обновления
- Тихий синтезированный звук монет при тапе (WebAudio), переключатель 🔊/🔇; проигрывается только после взаимодействия.
- Бонусные скины за игровые очки: Inferno (+1 за тап), Frost Pulse (+1 энергии/сек), Royal Crown (+2 за тап и +120/час). Бонусы вычисляются и проверяются на сервере.
- Скины Cyber Blue / Pink Nova за Telegram Stars остаются исключительно косметическими.
- Ник, имя и avatar Telegram подтягиваются из проверенных сервером Telegram initData. Если Telegram не передаёт photo_url, отображается первая буква имени. Вне Telegram — демонстрационный профиль.
- Переработаны панели, монета и карточки.

## Запуск Windows
Распакуйте, установите Node.js 20+, откройте CMD в папке проекта, выполните `npm start`. Затем http://localhost:3000. Для Telegram требуется BOT_TOKEN в переменной окружения и публичный HTTPS-адрес через Cloudflare Tunnel.

## Обновление текущего сервера
Остановите старый сервер (Ctrl+C). Замените server.js, public/index.html и public/coin.png файлами этого архива (не удаляйте data.json). Запустите `npm start`. Обновите страницу игры в Telegram.

Важное ограничение: файл data.json подходит для небольшого MVP, но не для серьёзной многопользовательской нагрузки. Размещайте в безопасной директории с резервным копированием. Не публикуйте BOT_TOKEN.
