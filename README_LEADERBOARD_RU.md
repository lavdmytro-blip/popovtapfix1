# POPOV TAP — рейтинг игроков

Откройте проект на Node.js 20+ командой `npm start`. В Telegram игроки авторизуются по подписанному `initData` и сохраняют имя, username и фото в серверное хранилище. Вкладка 🏆 Топ показывает 100 лучших по **текущему балансу** POPOV POINTS, включая username и аватар. При отсутствии username выводится имя Telegram. Профиль и баллы берутся с сервера, а не из браузера.

Обновление существующего проекта: обязательно замените **оба** файла `server.js` и `public/index.html`, оставив старый `data.json` или `DATA_FILE` и остальные файлы. Перезапустите `npm start`; откройте Telegram Mini App заново. Рейтинг не появится в демонстрационном режиме браузера без Telegram. Игроки появятся после первого входа в обновлённую игру.

Важно: локальные данные без постоянного диска теряются при смене среды. Для длительной эксплуатации используйте защищённую БД (PostgreSQL), аудит и защиту от злоупотреблений. Баллы не являются криптовалютой и не имеют денежной стоимости.
